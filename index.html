DEEP DIVE / PROJECT 78

Where the science meets the data.

View code & analysis ↗

A low-cost system using LEDs at 465, 625, 850 and 940 nm, a light sensor and a Raspberry Pi Pico to explore optical response in aqueous solvent mixtures.

4Optical wavelengths
0.93Cross-validated Q² for a reduced PLS model on solvent-spiked waste
2Selected wavelengths in that model
01

Measure — Build an optical setup, prepare standards and collect detector-response data.

02

Analyse — Clean, visualise and interpret signals using Python, PCA, PLS and cross-validation.

03

Validate limitations — Performance on one spiked waste matrix did not generalise to different real waste samples; matrix effects matter.

The model score describes a specific cross-validation experiment, not a universal claim of solvent quantification accuracy. That distinction is a central finding of the project.
